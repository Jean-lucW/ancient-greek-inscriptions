# Maresha, 300-101 BCE. Ostrakon. Letter. (IIP mare0050)

## Ancient Greek text

[...τοῖς? πρεσβυτ]έροις[...]  
[...δεῖνα? τοῦ] Διωνου[σίου?]

[...] ὑπὸ ἀυ  
[τ]οῦ πα´

### English translation

...To the Elders?/ so and so son of Dionisios/ .../ ... demanding/ ...from/ him 81 (drachmae?).
