# Epitaph of [---]enion (IOSPE 3.377)

## Ancient Greek text

[...]ενίων Χα[...]  
[ζῆσ]ας ἔτη [...]  
[...]κιανὸς Ἀλε[...]  
[τῷ] συνγενῖ τὸν [τύμβον?]  
[ἀνέ]στησεν· χ[αίρετε]  
παροδῖ[ται]

### English translation

[---]enion, (son of) Cha[---], having lived [---] years. [---]kianos, (son of) Ale[---], set up this grave monument for a relative. Greeting to you, passers by.
