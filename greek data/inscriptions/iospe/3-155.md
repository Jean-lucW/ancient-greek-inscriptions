# Honorific inscription (IOSPE 3.155)

## Ancient Greek text

ἐπὶ τᾶς συμμα  
χίας γενηθέν  
τι τᾶς πρὸς β[α]  
σιλέα Πολέμω  
να καὶ ἁγεμό  
[νεύσαντι].
