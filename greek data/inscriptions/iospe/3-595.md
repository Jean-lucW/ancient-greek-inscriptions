# Dedication to Athena Lindia (IOSPE 3.595)

## Ancient Greek text

[Ἀθ]ηνᾶι Λινδίαι  
[Ποσίδ]εος Ποσιδέου  
[χα]ριστήριον.

### English translation

Posideos, (son of) Posideos, (dedicated) to Athena Lindia, a thanks offering.
