# Building inscription of Aur. Dionysios (IOSPE 3.143)

## Ancient Greek text

Αὐρ(έλιος) Διονύσιος  
Πρείσκου ἐφιλο  
τειμήσατο εἰς  
τὸν κείονα  
τ

### English translation

Aur(elius) Dionysios, (son of) Priscus, donated for the column 300 denarii.
