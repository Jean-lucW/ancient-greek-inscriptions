# Altar dedicated to Astarte (RIB 1124)

## Ancient Greek text

Ἀστ[άρ]της  
βωμόν μ’  
ἐσορᾶς  
Ποῦλχέρ μ’  
ἀνέθηκεν

### English translation

You see me, an altar of Astarte; Pulcher set me up.
