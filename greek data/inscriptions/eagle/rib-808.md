# Dedication to Asclepius (RIB 808)

## Ancient Greek text

Ἀσκληπιῶ(ι)  
Α(ὖλος) Ἐγνάτιος  
Πάστορ ἔθηκεν

### English translation

To Asclepius Aulus Egnatius Pastor set this up.
