# Altar dedicated to the Saviour Gods (RIB 461)

## Ancient Greek text

[Θεοῖς]  
[σωτ]ῆρσιν  
ὑπερμενέσιν  
Ἑρμογένης  
ἰατρὸς βωμὸν  
τόνδ’ ἀνέθηκα

### English translation

To the mighty Saviour Gods I, Hermogenes, a doctor, set up this altar.
