# Honours for Sextus Appuleius (IAph2007 12.301)

## Ancient Greek text

ὁ δ[ῆ]μος  
Σέξτον Ἀππολήϊον  
τὸν [ἀ]νθύπατον

### English translation

The People set up this statue of Sextus Appuleius, the proconsul.
