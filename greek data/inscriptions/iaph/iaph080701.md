# Funerary inscription for Eirenion, gladiator (IAph2007 8.701)

## Ancient Greek text

Τροφίμη Εἰρηνί[ω]  
νι ἐϲϲεδαρίῳ μ[νεί]  
[αϲ] χάριν

### English translation

Trophime (put up this monument) to ?Eirenion, essedarius, in memory.
