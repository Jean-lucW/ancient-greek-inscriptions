# Dedication of a caryatid (IAph2007 5.222)

## Ancient Greek text

Κλ(αυδία) Παυλεῖνα  
ἀνέθηκεν

### English translation

Cl(audia) Paulina set (this) up.  

Claudia Pauleina set up (the statue).
