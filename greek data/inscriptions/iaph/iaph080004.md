# Statue Dedication for Demos by Kotas (IAph2007 8.4)

## Ancient Greek text

Ἀρτεμίδωρος  
Ἀπολλωνίου τοῦ Πε  
ρείτου · στεφανηφορή  
σας Κότας ἀνέθηκεν  
τῷ Δήμῳ τὴν εἰκόνα

### English translation

Artemidoros son of Apollonios the son of Pereitas former stephanephorus: Kotas set up the image for the People.
