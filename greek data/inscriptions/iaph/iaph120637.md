# Funerary inscription for Metrodoros from Zosimos (IAph2007 12.637)

## Ancient Greek text

Ζώϲιμοϲ Μητρό  
δωρον τὸν υἱὸν μνη[ϲ]  
χάριν

### English translation

Zosimos (set this up) in grateful memory of his son Metrodoros.  

Zosimos (set this up) in memory of Metrodoros (his) son.
