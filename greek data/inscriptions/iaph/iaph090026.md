# Honours for Antonia Augusta (IAph2007 9.26)

## Ancient Greek text

Ἀντωνίαν  
Σεβασστὴν  
Ἑρμίας ἱερεὺς ἀ  
νέθηκεν

### English translation

Antonia Augusta. Hermias priest, set (this) up.  

Antonia Augusta: Hermias, priest, put up (her statue).
