# Ephebic names (IRCyr2020 P.41)

## Ancient Greek text

Διόδωρος  
Λυσία  

Μαλ[...]υλης

(i) : Diodoros (son/friend) of Lysias

(iii) : Paraibatas.  

(iv) : -pimopes.
