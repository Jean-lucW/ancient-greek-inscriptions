# Funerary inscription (IRCyr2020 C.542)

## Ancient Greek text

(ἔτους) λε  

Μάτα  
Θεουδό  
του  
(ἐτῶν) ιζ  
παρθένοϲ  
παϲιποθητ  
όϲ

### English translation

(i) : Year 35.  

(ii) : Mata (daughter) of Theoudotos, aged 17, a maiden, missed by all.
