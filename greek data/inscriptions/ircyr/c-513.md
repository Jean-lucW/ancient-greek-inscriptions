# Funerary inscription (IRCyr2020 C.513)

## Ancient Greek text

Γάϊοϲ Ἀπείσιος  
Νίγερ πρεσβύτεροϲ  
(ἐτῶν) ν  

Διονύσω  
ἱερεύς

### English translation

Gaios Apeisios Niger [Gaius Apisius Niger] the elder, aged ?50, priest of Dionysos.
