# Acclamation (IRCyr2020 C.314)

## Ancient Greek text

Κλ(αυδίῳ) Μαρκιανῷ  
νέῳ  
τῷ ἀληθῶϲ καλλιέτει  
εὐτυχῶς

### English translation

For Kl(audios) Markianos [Cl(audius) Marcianus] the young(er), truly (priest) in a good year, with good fortune!
