# Building dedication for a column (IRCyr2020 C.253)

## Ancient Greek text

Μ(ᾶρκοϲ) [Κλ(αύδιοϲ)] Κλέαρχοϲ  
Μάγνοϲ τὸν  
κείονα ἐκ τῶν  
ἰδίων

### English translation

M(arkos) [Kl(audios M(arcus) [Cl(audius)]] Klearchos Magnos [Magnus] (gave) the column from his own resources.
