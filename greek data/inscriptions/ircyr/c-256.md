# Building dedication for a column (IRCyr2020 C.256)

## Ancient Greek text

Δ(έκμοϲ) Καϲ[κέλλιοϲ]  
Ἀριϲτο[τέληϲ]  
τὸν κεί[ονα]  
ἐκ τῶν [ἰδίων]

### English translation

Dekmos Kas[kellios] Aristo[teles] (gave) the column from [his own resources].
