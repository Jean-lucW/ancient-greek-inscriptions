# Honours for a priest (IRCyr2020 C.235)

## Ancient Greek text

Τι(βερίῳ) Κλαυδίῳ  
Τιβ(ερίω)  
α Θεοφράϲτῳ  
καλλιέτῃ  
ε

### English translation

For Ti(berios) Klaudios [Ti(berius) Cl(audius)] (son) of Tib(erios) [Tib(erius)], Theophrastos, (priest) in a good year.
