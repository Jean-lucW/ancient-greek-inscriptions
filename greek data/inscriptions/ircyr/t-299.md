# Funerary inscription (IRCyr2020 T.299)

## Ancient Greek text

Ϲεκόν  
δα (ἐτῶν) γ  
Μενελ  
άου (ἔτους) ιβ Φ  
αμενὼτ  
δ

### English translation

Sekonda [Secunda], aged 3 (daughter) of Menelaos, year 12, Phamenoth 4.
