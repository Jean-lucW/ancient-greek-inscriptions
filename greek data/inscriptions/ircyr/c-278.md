# Honours for Archippe (IRCyr2020 C.278)

## Ancient Greek text

[Ἀρχίππ]αν Πτολεμ[αίου]  
[συνιερι]τεύουϲαν Πτ[ολεμαίῳ]

### English translation

(Honours for) Archippa (daughter) of Ptolemaios, acting as priestess with Ptolemaios
