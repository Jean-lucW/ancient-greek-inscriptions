# Imperial honours for Julia (IRCyr2020 C.156)

## Ancient Greek text

[Ἰ]ουλίαν τὰν  
[Κ]αίσαρος τῶ Σεβαστῶ  
[θυ]γατέρα Κυραναῖοι

### English translation

Julia the daughter of Caesar the Augustus: the Cyrenaeans (honoured her)
