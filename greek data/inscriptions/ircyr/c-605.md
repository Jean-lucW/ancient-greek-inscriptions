# Funerary inscription (IRCyr2020 C.605)

## Ancient Greek text

[...]  

ᾧ μὴ ἀνῆκεν μή τι[να]  
[βάλ]λιν εἰ δὲ μή  
χρησόμεθα κατὰ  
τὸν νόμον

### English translation

. . .] to which it is not permitted to place anyone, and if not we use ?it according to the law.
