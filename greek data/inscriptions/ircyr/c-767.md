# Dedication to imperial divinities (IRCyr2020 C.767)

## Ancient Greek text

[Θ]εοῖς Σεβαστοῖς  
[Ἰσ]οκράτης Κλεάρ[χω]  
[ἱαριτεύ]ων

### English translation

For the deified Augusti, Isokrates (son) of Klearchos, serving as priest.
