# Dedication to the Samothracian Father (IRCyr2020 C.663)

## Ancient Greek text

Πατρὶ  
θεῶι  
Ϲαμόθρακι  
ἀθανάτωι  
ὑψίϲ[τωι]  

ἀλιτηρίωι

### English translation

(a) : For the Father, (b: avenging) God, Samothracian, immortal, highest.
