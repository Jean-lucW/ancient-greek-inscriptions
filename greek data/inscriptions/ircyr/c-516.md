# Funerary inscriptions, Tomb S.9 (IRCyr2020 C.516)

## Ancient Greek text

Μναϲιτίμω χ  

Ἀρίστ  
αρχοϲ  
Πανταλέ  
οντο[ϲ]  

{φ} Φιλύτα  

[...]δρα[...]  

Λέων  

Λαβρομείαϲ  

Ἐχεμήδαϲ  
Τιμοκρατείαϲ

### English translation

(a.1) : (Tomb of) Mnasitimos. (a.2) : Aristarchos (son) of Pantaleon. (a.3) : (Tomb of) Philutas.  

(b.2) : Leon  

(c) : (Tomb of) Labromeia  

(d) : (Tomb of) Echemeda (daughter?) of Timokrateia
