# Building inscription for a column (IRCyr2020 C.396)

## Ancient Greek text

Τι(βέριος) Κ[λαύδιος]

ἱαρειτεύων

### English translation

Ti(berios) K[laudios Ti(berius) C[laudius]] Phaos Titianos [Titianus], serving as priest (?erected this)
