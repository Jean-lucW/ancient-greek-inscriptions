# Honours for Octavia (IRCyr2020 C.453)

## Ancient Greek text

Ὀκταΐαν τὰν Καίσαρος  
τῶ Σεβάστω ἀδελφὰν  
[Κ]υραναῖοι

### English translation

Octavia the sister of Caesar Augustus (set up by) the Cyrenaeans
