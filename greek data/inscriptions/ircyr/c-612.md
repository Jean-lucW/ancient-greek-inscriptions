# Funerary inscription for Damo (IRCyr2020 C.612)

## Ancient Greek text

Δαμὸ  
Ῥόδα  
(ἐτῶν) ιϛ

### English translation

Damoroda, aged 16  

Damo (daughter) of Rhodas, aged 16.
