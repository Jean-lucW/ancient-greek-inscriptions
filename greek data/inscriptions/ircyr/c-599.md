# Caption for the statue of an athlete (IRCyr2020 C.599)

## Ancient Greek text

[Ἀντ]ωνιανὸϲ ὁ καὶ Μῶροϲ  
Ἐφέσιοϲ  

Παρή  
γοριϲ

### English translation

(a) Antonios [Antonius] also called Moros, an Ephesian.  

(b) Paregoris
