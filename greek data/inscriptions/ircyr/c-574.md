# Captions for wall-paintings, Tomb N.173 (IRCyr2020 C.574)

## Ancient Greek text

Ψυχή  

Λήδα  

Ἀκταίων  

Ἄδ[ωνις?]  

[Μοῖρ]αι  

[Γανυμ?]ήδ[ης]

### English translation

i: Psyche. ii: Leda; iii: Akteon; iv: Adonis; v: The Fates; vi: Ganymede.
