# Funerary inscription (IRCyr2020 M.81)

## Ancient Greek text

Νείκαΐ  
ϲ Θευδό  
τω ἐτῶν δ  
έκατεϲερ  
ων

### English translation

Neikais (child) of Theodotos, aged 14.
