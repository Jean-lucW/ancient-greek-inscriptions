# Funerary inscription (IRCyr2020 C.751)

## Ancient Greek text

[Ἰ]ωναθᾶϲ Θευ  
δοϲίου  
ἐτῶν ξε

### English translation

Ionathas (son) of Theudosios, aged 65.
