# Funerary inscriptions (IRCyr2020 C.597)

## Ancient Greek text

Κ(όϊντος) Πλωτῆνος Μάκερ  
(ἐτῶν) ξ  
[Ἄ]στεια Ἀσία (ἐτῶν) ν  
Πλωτῆνα Ἀσία  
(ἐτῶν) κ  
Πακωνία  
Παῦλλα  
(ἐτῶν) κβ

### English translation

Quintus Plotenos Macer, aged 60; Asteia Asia, aged 50; Plotena Asia, aged 20; Paconia Paulla aged 22.
