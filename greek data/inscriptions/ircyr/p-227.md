# Funerary inscription (IRCyr2020 P.227)

## Ancient Greek text

(ἔτους) α Ζηνοδώρα Εὐκράτ(ουϲ) (ἐτῶν) ϙ  
(ἔτους) ι [...]ποϲ Πρωτάρχου (ἐτῶν) πη  
(ἔτους) ι Ἀριϲτόνομοϲ (ἐτῶν) πϛ  
(ἔτους) [...] Φίλιπποϲ Δέγμου (ἐτῶν) ιη  
(ἔτους) ι Κλουτώριοϲ Κλουτωρίου (ἐτῶν) κδ  
(ἔτους) ι Θεύλυτοϲ Δέγμου (ἐτῶν) κδ  
(ἔτους) ι Κοάρτα Λύκου (ἐτῶν) κδ  
(ἔτους) ια Νείκη Δέγμου (ἐτῶν) κϛ  
(ἔτους) ι Κλουτώριοϲ Δέγμου (ἐτῶν) ιη  

(ἔτους) [...] Λύκοϲ Ἀγαθοκλεῦϲ (ἐτῶν) θ  
(ἔτους) [...] Ἀριστονόα Λύκου (ἐτῶν) ι  
(ἔτους) ι Ἴαλ Δέγμου (ἐτῶν) κα  
(ἔτους) δ Ἀριστονόα [...]  
ϲαϲτ [...]
