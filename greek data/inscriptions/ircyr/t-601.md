# Funerary inscription (IRCyr2020 T.601)

## Ancient Greek text

(ἔτους) α Παχὼν α  
Δ(έκμος) Ἰoύνιος  
Ἀλέξαν  
δρος (ἐτῶν) ο

### English translation

Year 1, Pachon 1, Dekmos Iounios [Decimus Junius] Alexander, aged 70.
