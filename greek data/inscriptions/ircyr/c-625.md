# Funerary inscription, Tomb S.147 (IRCyr2020 C.625)

## Ancient Greek text

[ὑγ]ί[α]ινε κα  
λὲ κἀγαθὲ  
Σ[ε]κόνδε

### English translation

Be well, Sekondos [Secundus], noble and good!
