# List of priestesses of Hera (IRCyr2020 C.142)

## Ancient Greek text

θεὸς Τύχα ἀγαθά  
Ἱάρεαι τᾶς Ἥρας  
Μεγὼ Φιλοξένω  
Δαμοκλήτα Ξούθω  
Βερενίκα Πραξιάδα  
Ἀπία Πτολεμαίω  
[Ζ]ευξίππα Βαρκαίω  
Εὐρυκλήτα Ἀσκλάπω  
Ζευξὼ Φειδίμω  
Ἐπαγὼ Καρνήδα  
[Φ]ιλυλλιὼ Λύσιος  
Φρονίμα Φιλοξένω  
Εἰρήνα Τελεσιστράτω  
Βερνίκα Φιλίννα  
[Κ]αλλιβώλα Κλεάρχω  
Μνάστα Φιλύ[τ]α  
Νικαρίστα Θρασυκλεῦ[ς]  
Ἀράτα Φιλώτα  
[...] Φιλύτα
