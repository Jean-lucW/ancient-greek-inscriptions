# Funerary inscription (IRCyr2020 P.261)

## Ancient Greek text

Μᾶρκοϲ Ϲοέλλιοϲ ἐπ  
ούησεν ἡατῶ κὲ τ  
[ῦϲ τέκνυϲ αὑτ[ῶ]]

### English translation

Markos Soellios [Marcus Soellius] set this up for himself and his children.
