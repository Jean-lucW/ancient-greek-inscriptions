# Funerary inscription (IRCyr2020 C.534)

## Ancient Greek text

Γ(άϊος) Εὐθυκλ(ῆς)  
(ἐτῶν) ξη  
ἱερ(εὺς) Διονύ(σου)

### English translation

G(aios) [G(aius)] Euthykles, aged 68, priest of Dionysos
