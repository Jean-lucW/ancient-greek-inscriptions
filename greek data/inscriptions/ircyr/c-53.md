# Acclamation (IRCyr2020 C.53)

## Ancient Greek text

[ε]ὐτυχῶϲ Βενούϲτῳ τῷ ἀρχιερ⟨ε⟩ῖ

### English translation

With good fortune for Benoustos the high-priest
