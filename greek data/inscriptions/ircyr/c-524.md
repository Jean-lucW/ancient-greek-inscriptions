# Funerary inscriptions, Tomb S.255 (IRCyr2020 C.524)

## Ancient Greek text

τ  
Ἰάσων (ἐτῶν) μ  
Λόγγος  
(ἐτῶν) ε  
Πόλλις (ἐτῶν) δ

### English translation

Jason [died] aged 40. Longos, aged 5. Pollis, aged 4.
