# Building dedication for a column (IRCyr2020 C.254)

## Ancient Greek text

Μ(ᾶρκοϲ) Κλ(αύδιοϲ) Κλέαρχοϲ  
Ῥοῦφοϲ Μα  
γνος τ[ὸν]  
κε[ίονα ἐκ]  
[τῶν ἰδίων]

### English translation

M(arkos) Kl(audios) [M(arcus) Cl(audius)] Klearchos Rouphos Magnos [Rufus Magnus] (gave) the column [from his own resources].
