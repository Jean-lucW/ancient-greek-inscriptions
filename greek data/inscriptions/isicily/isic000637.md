# Funerary inscription from Syracusae, modern Siracusa (I.Sicily ISic000637)

## Ancient Greek text

Π(ούβλιε) · Κλώδιε  
Κορνηλιανὲ  
εὐσεβῆ · χαῖρε

### English translation

Publius Claudius Cornelianus, a pious man, farewell.
