# Bilingual funerary inscription for Quintus Domitius (I.Sicily ISic000348)

## Ancient Greek text

Κόϊντε · Δομίτιε  
εὐσεβῆ · χαῖ ρε

### English translation

Quintus Domitius, pious, farewell! Quintus Domitius, pious, farewell!
