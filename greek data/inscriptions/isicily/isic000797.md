# Funerary inscription from Sicilia, modern Sicily (I.Sicily ISic000797)

## Ancient Greek text

Θ(εοῖς) κ(αταχθονίοις)  
Μ(άρκος) · Ἀκύλιος  
Αἰλιανὸς · ἔ

μ· σύμβιος  
ἀνδρὶ εὐσεβεῖ
