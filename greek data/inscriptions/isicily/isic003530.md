# Funerary inscription from Messana, modern Messina (I.Sicily ISic003530)

## Ancient Greek text

[Θ(εοῖς)] Κ(αταχθονίοις)  
[Κλ(ώδιος)?] Ῥωμανὸς  
ἔζ(ησεν) ❦ [ἔ] τ(η) ❦ α ❦ μ(ῆνας) ❦ [...]❦ ἡ(μέρας) ❦ κη  
Κλ(ώδιος) ❦ Θησεὺς ❦ πατὴρ  
τέκ(νῳ) ❦ γλυκυτάτ(ῳ)
