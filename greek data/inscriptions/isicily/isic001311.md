# Epitaph for Libios (I.Sicily ISic001311)

## Ancient Greek text

[Λίβιος]  
[χρ]ηστὸς  
[κα]ὶ ἄμεμ  
[πτ]ος ἔζη  
[σεν] ἔτη κη

### English translation

Libios, honest and blameless, lived for 28 years.
