# Lex sacra inscription from Megara Hyblaea, modern Megara Iblea (I.Sicily ISic001424)

## Ancient Greek text

Πασι : ἀρὰ : το͂ : [θ]  
[ε]ο͂ : hάδε : hὸς κ  
ὰ⟨τ⟩ το͂ ἀρχομ  
άο θύε ὀγδ  
όαν ἀποτει  
σάτο̄ : αἰ δὲ[...]Ν[...]Α[...]ΑΘ[...]ΔΕ  
κα λιτρὰς : ἀ  
ποτεισάτο̄

### English translation

For everyone the law of the god (is) this: whoever sacrifices against (the will of) the archomaos pays the eighth (part); if then...
